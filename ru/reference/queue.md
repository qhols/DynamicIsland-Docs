# DynamicIslandQueue

`DynamicIslandQueue:` **`table[]`**

Глобальный список, в который может писать кто угодно. Каждый кадр островок забирает из него уведомления и показывает. Пригодится, если твой скрипт выполняется раньше островка, например прямо в начале файла.

```lua
DynamicIslandQueue = DynamicIslandQueue or {}
table.insert(DynamicIslandQueue, {
    app = "My Script",
    title = "Загружен и готов",
    icon = "check",
    level = "passive"
})
```

Каждый элемент это та же таблица, что ты передал бы в [`Notify`](notify.md).

## Полезно знать

* На уведомления из очереди действуют те же [лимиты](../guides/limits-and-safety.md), что и на `Notify`.
* Островок забирает до 20 элементов за кадр.
* Всегда сначала пиши `DynamicIslandQueue = DynamicIslandQueue or {}`, список мог уже создать другой скрипт.
* Если какой-то скрипт положит туда не список, островок сбросит его и напишет об этом в консоль.

{% hint style="info" %}
Когда островок уже загружен, проще вызывать `DynamicIsland.Notify` напрямую, так ты сразу получишь результат.
{% endhint %}
