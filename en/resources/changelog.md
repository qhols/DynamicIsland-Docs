# Changelog

## API 1

The first version.

* `DynamicIsland.Notify` with levels, sounds, icons, tints, a trailing pill, a body and up to 2 actions.
* `DynamicIsland.Activity.Start` with a timer, progress, trailing text, `onTap`, `onEnd` and `staleAfter`.
* `End` with final content and `after`.
* `DynamicIslandQueue` for scripts that load before the island.
* `DynamicIsland.PlaySound`, `Has`, `IsAllowed` and `Glyphs`.
* A permission prompt for every script, with a list of scripts and Allow in Focus in the island's settings.
